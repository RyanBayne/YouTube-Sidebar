# YouTube Sidebar

[![WordPress](https://img.shields.io/badge/WordPress-5.0%2B-blue.svg)](https://wordpress.org/)
[![PHP Version](https://img.shields.io/badge/PHP-7.4%2B-purple.svg)](https://php.net)

> Display YouTube videos in your sidebar on a per-post basis with responsive embeds, shortcodes, and widget support.

---

## Features

- **Per-Post Video Assignment** — Assign different YouTube videos to individual posts
- **Multiple Videos Per Post** — Display more than one video per post
- **Responsive Embeds** — Modern responsive YouTube embeds for video, playlist, channel, and live-stream sources
- **Widget Support** — Two configurable widgets for sidebar display
- **Shortcode Support** — Embed videos anywhere with shortcodes
- **Ad Fallback** — Display an advertisement when no video is assigned to a post
- **Legacy Compatibility** — Works with existing custom field video assignments

---

## Installation

1. Upload the `youtube-sidebar` folder to `wp-content/plugins/`
2. Activate the plugin through the WordPress Plugins menu
3. Configure widgets under Appearance → Widgets
4. Assign videos to posts using the meta box on the post editor

---

## Usage

### Widget
Add the YouTube Sidebar widget to any widget area via Appearance → Widgets.

### Shortcode
```
[youtube_sidebar video_id="dQw4w9WgXcQ"]
```

### Per-Post Assignment
Edit any post and use the YouTube Sidebar meta box to assign video IDs.
